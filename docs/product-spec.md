# Lunagrove product specification

Lunagrove is a gentle Chrome Pomodoro extension. Every completed focus session permanently restores one part of a moonlit pixel-art sanctuary. Progress never regresses, cancelled sessions carry no penalty, and all data stays on the device.

The first release contains a customizable 25/5 timer, a twenty-stage sanctuary, local statistics, optional notifications, reduced-motion support, and JSON backup and restore.
