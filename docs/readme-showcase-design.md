# GitHub README Showcase

## Goal

Present Lunagrove as a polished international open-source Chrome extension while making Lumi the emotional center of the project.

## Direction

- English-first copy for international reach.
- A large, transparent Lumi portrait at the top.
- The approved extension screen immediately below the introduction.
- Short, concrete product language: focus, grow, return.
- Pixel-art dividers and small visual accents without turning the README into a wall of badges.

## Structure

1. Centered title, tagline, status badges, and Lumi.
2. Approved product screenshot.
3. Product promise and current feature highlights.
4. How the twenty-session journey works.
5. Local installation and unpacked-extension instructions.
6. Stack, project status, roadmap, and contribution guidance.

## Visual assets

- Crop Lumi directly from the approved local sprite sheet.
- Use `lunagrove-home.png` as the product screenshot.
- Keep all images in `docs/assets/` so GitHub renders them reliably.

## Voice

Warm, concise, game-like, and credible. Avoid exaggerated marketing language and avoid presenting unfinished Garden or Map views as already available.
